Let's get you set up

This app needs two things before it can make playlists for you.

  • Claude

    1. Install Claude Code from the official install page.
    2. Open a terminal. On Windows, press Start, type Terminal and open it. On a Mac, open Terminal from Applications, then Utilities.
    3. Type claude, press Enter, and follow the steps to log in. You can close the terminal afterwards.
    4. Come back here and press Check again.

  • YouTube Music

    Connect your YouTube Music account by copying a few details from your web browser. It takes about two minutes. Pick the browser you use:

    1. Open music.youtube.com in Chrome or Edge and make sure you are signed in.
    2. Press F12 to open the developer tools. On a Mac, press Cmd+Option+I.
    3. Click the Network tab at the top of the developer tools.
    4. Type browse into the filter box. If the list stays empty, click Home or Library on the YouTube Music page.
    5. Right-click the first request in the list, then choose Copy and then Copy request headers.
    6. Paste them into the box below (Ctrl+V, or Cmd+V on a Mac) and press Connect.
    1. Open music.youtube.com in Firefox and make sure you are signed in.
    2. Press F12 to open the developer tools. On a Mac, press Cmd+Option+I.
    3. Click the Network tab at the top of the developer tools.
    4. Type browse into the Filter URLs box. If the list stays empty, click Home or Library on the YouTube Music page.
    5. Click the first request in the list. On the right, find Request Headers and switch on the Raw toggle next to it.
    6. Select all of the text under Request Headers, copy it, paste it into the box below and press Connect.

    These details let this app act as you on YouTube Music. They stay on this computer only.
